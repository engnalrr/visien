Visual Enhancer engine folder

Optional: extract the Visual Enhancer release package (the large .zip from
https://github.com/Merserk/dlss5-visual-enhancer/releases/latest) here, so that VE_CLI.exe
ends up in this folder or one folder below it. Visien also finds Visual Enhancer in your
Downloads, Desktop and Documents folders, or you can choose its folder in Settings.

Visual Enhancer is made by Merserk and is not part of Visien.
